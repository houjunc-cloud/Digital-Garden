# Characters

One section per character. Backstory is only worth writing down if it changes
behaviour on the page — the rest is procrastination that feels like work.

## Template per character

**Name** —

- **Wants (stated):** what they'd say if you asked
- **Needs (actual):** what would genuinely resolve them, which they can't see
- **Lie they believe:** the thing that has to break
- **Contradiction:** the trait that argues with another trait — this is where character comes from
- **Voice:** one line of dialogue only they would say
- **Leaves the story:** how, and changed how
