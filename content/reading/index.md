Book notes, article clippings, and links worth keeping. The rule: no note without a
takeaway. A list of things I've read is a vanity metric; a list of things that changed
how I think is a resource.

## Format

Each note holds the source, a one-line verdict, the ideas worth keeping (in my own
words, not quoted), and where I disagreed. Quotes are fine, but a note that is *only*
quotes means I didn't understand the book — I transcribed it.

## Verdict scale

- **Reread** — I'll come back to this
- **Worth it** — got real value, done with it
- **Skim** — one good chapter, rest padding
- **Skip** — say so and why, so I don't pick it up again
