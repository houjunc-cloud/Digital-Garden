# Links are the unit of insight, not notes

A note stored and never re-encountered is worth roughly nothing. The reason a linked
system beats a folder of documents isn't storage — it's that links create the
collisions where ideas from different contexts meet.

The practical consequence: when writing a note, the highest-value minute is spent
asking *what does this connect to?* rather than *how do I phrase this?* Phrasing can
be fixed later. An unmade connection is invisible forever.

## The test

A link is worth making if you can finish this sentence: "If you're reading A, you
should read B **because** ___." If the because clause is "they're both about
productivity", it's a tag, not a link.

## Open question

Does the graph view actually surface useful collisions, or does it just visualise
links you already knew about? Suspect the latter, but backlinks — which surface
connections made *after* you wrote the note — may be the part that earns its keep.
