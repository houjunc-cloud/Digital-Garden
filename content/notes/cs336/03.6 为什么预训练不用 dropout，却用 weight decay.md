# 03.6 为什么预训练不用 dropout，却用 weight decay

出处：CS336 第 3 讲（Tatsu Hashimoto），第 48–51 页。所属栏目：[[notes/cs336/index|CS336：从零构建语言模型]]。§3 的结论用一个小模拟验证过。

**术语预备**
- **正则化**：为了防止过拟合（训练集上好、新数据上差）而加的约束。
- **dropout**：训练时把每个激活以概率 $p$ 随机置零（其余的放大 $1/(1-p)$）。
- **weight decay**：每一步把权重往 0 拉一点，$w\leftarrow w-\eta\lambda w$。$\lambda$ 是衰减系数，常取 0.1。
- **AdamW**：把 weight decay 和 Adam 的梯度更新**分开**做的 Adam（§4）。A1 要实现的就是它。
- **学习率调度**：学习率随训练步数变化。最常见的是先 warmup，再按余弦曲线降到很小（cosine schedule）。

## 0. 问题：大模型还要不要正则化

讲义第 48 页先列了"不需要"的理由：
- 数据极多（万亿个 token），比参数还多。
- 只把语料过一遍，很难记住。

"This is all quite reasonable.. but what do people do in practice?" 第 49 页的表：

| 模型 | dropout | weight decay |
|---|---|---|
| 原始 Transformer | 0.1 | 0 |
| GPT-2 | 0.1 | 0.1 |
| T5 | 0.1 | 0 |
| GPT-3 | 0.1 | 0.1 |
| T5 v1.1 | 0 | 0 |
| PaLM | 0 | （可变） |
| OPT | 0.1 | 0.1 |
| LLaMA | 0 | 0.1 |
| Qwen 14B | 0.1 | 0.1 |

讲义的总结："Many older models used dropout during pretraining. Newer models (except Qwen) rely only on weight decay." 还有一条注释：很多论文根本不提 dropout，开源模型的代码里通常就是没有。

于是有两个问题：dropout 为什么消失了？weight decay 为什么留下来，它在做什么？

## 1. dropout 为什么消失了

dropout 是为了防过拟合。过拟合的前提是同一批数据被反复看很多遍，模型开始记住训练集的细节。预训练通常只把语料过一遍，**每个 token 只见一次**。这时候训练 loss 就是在"新数据"上的 loss，和验证 loss 之间没有差距，也就没有过拟合可防。

dropout 还有代价：
- 它往训练里加了噪声，收敛会变慢。
- 掩码要存下来给反向用，多占显存；它本身是逐元素运算，带宽受限（[[02.3 算术强度与 roofline]]）。

既然没有好处、只有代价，新模型就把它去掉了。A1 的模型里也没有 dropout。（在小数据上微调时，多轮训练又会出现过拟合，那时 dropout 可能重新有用。）

## 2. weight decay 不是为了防过拟合

讲义第 50 页引了 Andriushchenko 等人（2023）的两个观察。

**第一，它不影响泛化.** 用 weight decay 0、0.1、0.3 训练的模型，画出"训练 loss 对验证 loss"，所有点落在同一条直线上。weight decay 没有改变两者之间的关系，所以它不是在防过拟合。

**第二，它和学习率调度相互作用.** 用余弦学习率时：
- 训练中段，weight decay 越大，loss 反而**越高**。
- 学习率降到底以后，weight decay 大的模型 loss **更低**。

用恒定学习率时，加了 weight decay 的模型在最后把学习率调得很小，loss 也会突然降下来。

讲义的结论："You still 'regularize' LMs but its effects are primarily on optimization dynamics." 下面给出一个能把这些现象串起来的解释。

## 3. 一个解释：权重的长度决定"有效学习率"

### 3.1 接在归一化后面的权重，只有方向重要

设权重 $w$ 的输出马上要经过一个归一化（比如 QK norm 里的 $W_Q,W_K$，[[03.7 训练稳定性：z-loss、QK norm、logit soft-capping]]）。归一化对缩放不变（[[03.2 从 LayerNorm 到 RMSNorm，以及去掉 bias]] §1），所以 loss 只依赖 $w$ 的方向：

$$\mathcal L(cw)=\mathcal L(w)\qquad(c>0).$$

对 $c$ 求导，在 $c=1$ 处得到 $\langle\nabla\mathcal L(w),w\rangle=0$，**梯度和 $w$ 正交**；再对 $w$ 求导可得 $\nabla\mathcal L(cw)=\nabla\mathcal L(w)/c$，**权重越长，梯度越小**。

### 3.2 不加 weight decay：权重越长越大，学习悄悄变慢

更新量 $\Delta$ 和 $w$ 正交，由勾股定理

$$\lVert w+\Delta\rVert^2=\lVert w\rVert^2+\lVert\Delta\rVert^2>\lVert w\rVert^2 .$$

**每走一步，权重都会变长.** 真正影响模型的是方向，每一步方向转过的角度约为 $\lVert\Delta\rVert/\lVert w\rVert$，可以叫它"有效学习率"。权重越来越长，这个角度就越来越小。于是即使学习率不变，学习也会悄悄变慢，而且慢多少取决于初始化的大小和训练的历史，不受控制。

### 3.3 加上 weight decay：长度被钉在一个平衡点上

AdamW 的一步是 $w\leftarrow w-\eta(u+\lambda w)$，其中 $u$ 是 Adam 算出的更新方向。Adam 把每个坐标都除以了梯度的均方根，所以 $u$ 每个坐标的量级大致固定，和 $\lVert w\rVert$ 无关。两股力量：
- 更新让 $\lVert w\rVert^2$ 每步大约增加 $\eta^2d$（$d$ 是 $w$ 的维数；带动量时单步的更新小一些，但相邻几步方向相关，累积起来仍约是这个量）；
- weight decay 让它每步减少约 $2\eta\lambda\lVert w\rVert^2$。

两者相等时达到平衡：

$$\lVert w\rVert^2\approx\frac{\eta d}{2\lambda}.$$

此时每一步转过的角度正比于 $\sqrt{\eta\lambda}$，**只由学习率和衰减系数决定，与初始化无关**。到达平衡大约需要 $1/(\eta\lambda)$ 步。

**模拟验证.** 取 $d=1024$ 维的权重，梯度随机、与 $w$ 正交、大小按 $1/\lVert w\rVert$ 缩放（满足 §3.1 的性质），用 AdamW 更新 40000 步：

| 设置 | 初始长度 | 1000 步 | 10000 步 | 40000 步 | 40000 步时每步转角 |
|---|---|---|---|---|---|
| $\eta=10^{-3}$，$\lambda=0.1$ | 1 | 1.32 | 2.11 | **2.24** | 0.0032 |
| $\eta=10^{-3}$，$\lambda=0.1$ | 30 | 27.2 | 11.2 | **2.31** | 0.0031 |
| $\eta=10^{-3}$，$\lambda=0$ | 1 | 1.42 | 3.32 | 6.43 | 0.0011 |
| $\eta=10^{-3}$，$\lambda=0$ | 30 | 30.0 | 30.2 | 30.7 | 0.0003 |
| $\eta=3\times10^{-4}$，$\lambda=0.1$ | 1 | 1.01 | 1.11 | 1.21 | 0.0018 |

- 平衡点的预测是 $\sqrt{\eta d/(2\lambda)}=\sqrt{10^{-3}\times1024/0.2}=2.26$。两种初始化最后都到了 2.24 和 2.31，转角也一样，初始化被"忘掉"了。$\eta=3\times10^{-4}$ 时预测 1.24，实测 1.21，还在收敛中。
- 两组的转角之比 $0.0032/0.0018=1.78$，和 $\sqrt{10^{-3}/(3\times10^{-4})}=1.83$ 相符，转角确实正比于 $\sqrt{\eta\lambda}$。
- 不加 weight decay：从 1 开始的权重一路变长，转角掉到 0.0011，还在继续变小；从 30 开始的那个几乎不动，转角只有 0.0003，**是有 weight decay 时的十分之一**，学习率等于白设了。

### 3.4 用它解释讲义的图

有了 weight decay，学习率调度才真正掌控了"每步转多大角度"：
- **训练中段**：weight decay 大，平衡点的长度短，每步转角大，相当于有效学习率更高。噪声也大，所以 loss 看起来更高。
- **训练末段**：余弦调度把 $\eta$ 降下来，转角随 $\sqrt\eta$ 变小，噪声被压下去，之前积累的进展兑现成更低的 loss。

这正是第 50 页那张图的形状。不加 weight decay 时，有效学习率早就被权重的增长悄悄压低了，末段降学习率能起的作用也就小。

**保留.** 以上推导对"接在归一化后面"的权重是精确的。在 pre-norm Transformer 里，并非所有矩阵都满足缩放不变，比如 $W_O$、$W_2$ 的输出直接加回残差流。所以它是一个机制，不是全部的解释。

## 4. AdamW：为什么要把 weight decay 单独拿出来

最朴素的做法是在 loss 里加一项 $\tfrac\lambda2\lVert w\rVert^2$（L2 正则），梯度多出 $\lambda w$。在 SGD 里，这和 weight decay 完全一样。但在 Adam 里，梯度会被每个坐标的 $\sqrt{v}$ 除掉，$\lambda w$ 这一项也被除掉了：梯度大的坐标衰减得少，梯度小的坐标衰减得多，衰减的强度变得不均匀，也不再是"每步把权重拉回固定的比例"。

AdamW（Loshchilov 和 Hutter）的做法是把衰减从梯度里拿出来，单独做一步：

$$w\leftarrow w-\eta\Big(\frac{\hat m}{\sqrt{\hat v}+\varepsilon}+\lambda w\Big).$$

§3.3 的平衡点就是基于这个形式推出来的。A1 的 AdamW 算法里，最后一行 $\theta\leftarrow\theta-\alpha\lambda\theta$ 就是这一步。

**哪些参数衰减.** 惯例是只衰减矩阵，不衰减归一化的增益 $\gamma$ 和 bias。讲义第 66 页 OLMo 3 的配置表里还写着 "Weight decay on embeddings: No"。在 PyTorch 里用参数组实现：

```python
decay    = [p for n, p in model.named_parameters() if p.dim() >= 2 and "emb" not in n]  # 矩阵
no_decay = [p for n, p in model.named_parameters() if p.dim() < 2 or "emb" in n]     # 增益、bias、嵌入
opt = torch.optim.AdamW([
    {"params": decay, "weight_decay": 0.1},
    {"params": no_decay, "weight_decay": 0.0},
], lr=3e-4, betas=(0.9, 0.95))
```

Python 要点：
- `named_parameters()` 逐个给出（参数名，参数）。`p.dim() >= 2` 用来挑出矩阵，一维的是增益或 bias。
- 优化器可以接收一个字典列表，每组参数用自己的超参数，没写的沿用后面的默认值。

## 5. 总表

| | dropout | weight decay |
|---|---|---|
| 原本的用途 | 防过拟合 | 防过拟合 |
| 预训练里还需要吗 | 不需要：每个 token 只见一次，没有过拟合可防 | 需要，但作用变了 |
| 实际作用 | 加噪声，拖慢收敛 | 把权重长度钉在平衡点 $\sqrt{\eta d/2\lambda}$，让有效学习率由 $\eta\lambda$ 决定 |
| 现状 | 新模型基本去掉（Qwen 例外） | 几乎都用，常取 0.1 |
| 实现 | — | AdamW 的解耦衰减；只衰减矩阵，常不衰减嵌入 |

一句话：预训练每个 token 只见一次，dropout 没什么可防的；weight decay 留下来，是因为它把接在归一化后面的权重的长度钉在一个平衡点上，让每一步的有效步长只由学习率和衰减系数决定，学习率调度才能真正控制训练，末段降学习率时 loss 才降得下去。

## 练习

1. **推导.** 从 $\mathcal L(cw)=\mathcal L(w)$ 出发，证明 $\langle\nabla\mathcal L(w),w\rangle=0$ 和 $\nabla\mathcal L(cw)=\nabla\mathcal L(w)/c$。
2. **推导.** 换成普通 SGD 加 weight decay：$w\leftarrow w-\eta(\nabla\mathcal L+\lambda w)$，梯度大小是 $g/\lVert w\rVert$（$g$ 是 $w$ 取单位长度时的梯度大小）。求 $\lVert w\rVert$ 的平衡点，以及平衡时每步的转角。
3. **思考.** 为什么一般不对 RMSNorm 的增益 $\gamma$ 做 weight decay？

## 练习答案

1. 对 $c$ 求导：$\frac{d}{dc}\mathcal L(cw)=\langle\nabla\mathcal L(cw),w\rangle=0$，取 $c=1$ 即得正交。对 $w$ 求导：$\mathcal L(cw)=\mathcal L(w)$ 两边对 $w$ 求梯度，左边是 $c\,\nabla\mathcal L(cw)$，右边是 $\nabla\mathcal L(w)$，所以 $\nabla\mathcal L(cw)=\nabla\mathcal L(w)/c$。
2. 每步增长约 $\eta^2g^2/\lVert w\rVert^2$，衰减约 $2\eta\lambda\lVert w\rVert^2$。相等时 $\lVert w\rVert^4=\eta g^2/(2\lambda)$，即 $\lVert w\rVert=(\eta g^2/2\lambda)^{1/4}$。每步转角 $\eta g/\lVert w\rVert^2=\eta g\sqrt{2\lambda/(\eta g^2)}=\sqrt{2\eta\lambda}$，同样只由 $\eta\lambda$ 决定。
3. $\gamma$ 不是"接在归一化后面"的权重，它就是归一化输出的缩放本身，对它做衰减只会把输出往 0 拉，没有 §3 那种调节有效学习率的作用。它的参数量也很小，衰减它得不到什么，反而可能损害表达能力。
