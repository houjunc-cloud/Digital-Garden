### 1. 单头注意力（一层里的一个头）

输入是 $n$ 个 token 的向量 $h_1,\dots,h_n\in\mathbb R^d$。这些向量所在的空间叫**残差流**，每一层都从里面读，再把结果加回去。

**① 投影.** 用三个矩阵 $W_Q,W_K,W_V\in\mathbb R^{d_{\text{head}}\times d}$ 把每个位置的向量投影成三份：

$$q_m=W_Qh_m,\qquad k_m=W_Kh_m,\qquad v_m=W_Vh_m.$$

**② 打分.** 对位置 $m$ 和它之前的每个位置 $n\le m$，计算 $s_{mn}=q_m^\top k_n/\sqrt{d_{\text{head}}}$。限制 $n\le m$ 是因为因果遮罩不允许看后面。

**③ 归一化.** 对 $n$ 做 softmax，得到权重 $a_{mn}\ge0$，满足 $\sum_n a_{mn}=1$。

**④ 加权平均.** 输出 $o_m=\sum_n a_{mn}v_n$。

直观上，位置 $m$ 用自己的 $q_m$ 去和前面所有位置的 $k_n$ 比对，比对得越好权重越大，最后取回这些位置的 $v_n$ 的加权平均。$k$ 决定“找谁”，$v$ 决定“拿回什么”。

所有 $a_{mn}$ 排成一个 $n\times n$ 的下三角矩阵，叫做这个头的**注意力模式**。

### 2. 多头

一次 softmax，只能让每个位置得到**一个**加权平均，也就是一种“查找方式”。多头就是让 $H$ 个头**并行**地做上面四步：

- 每个头 $h$ 都有**自己的** $(W_Q^h,W_K^h,W_V^h)$，互相独立。
- 每个头各算各的注意力模式 $a^h_{mn}$ 和输出 $o^h_m\in\mathbb R^{d_{\text{head}}}$。
- 把各头的输出拼起来，再乘一个输出矩阵 $W_O\in\mathbb R^{d\times d}$，然后加回残差流：

$$h_m\ \leftarrow\ h_m+W_O\begin{pmatrix}o^1_m\\ \vdots\\ o^H_m\end{pmatrix}=h_m+\sum_{h=1}^H W_O^h\,o^h_m,$$

这里 $W_O^h$ 是 $W_O$ 中对应第 $h$ 个头的那一块列。

- 接着过一个 MLP，同样加回残差流。这就是一层。整个模型把这样的层叠 $L$ 次。

通常取 $d_{\text{head}}=d/H$，所以多头的计算量和一个维数为 $d$ 的大头差不多。换来的是：同一个位置可以**同时**按好几种标准去看好几个地方。以 Llama 2 7B 为例：$d=4096$，$H=32$，$d_{\text{head}}=128$，共 32 层，所以一共有 $32\times32=1024$ 组 $(W_Q^h,W_K^h)$。

真实的顺序是 attention、FFN、attention、FFN……交替进行。

### 两个子层各干什么

把一层的输入写成矩阵 $X\in\mathbb R^{n\times d}$，$n$ 个 token，每个 token 占一行。下面暂时忽略多头和因果掩码。

- **Attention**：$X\mapsto A(X)\,XW_VW_O$，其中 $A(X)\in\mathbb R^{n\times n}$ 是 softmax 权重矩阵。它从**左边**乘上去，混合的是不同的行，也就是让 token 之间互相交换信息。
- **FFN**：$X\mapsto\big[f(x_1);\dots;f(x_n)\big]$，用同一个函数 $f:\mathbb R^d\to\mathbb R^d$ 逐行作用。它只在每一行内部变换特征，token 之间不交流。

一个负责混 token，一个负责混特征维度，两者互补。

### 为什么不能只堆 attention

固定 $A$ 之后，attention 对 $X$ 是线性的。每个 token 的输出只是若干 value 向量的凸组合，再做一次线性变换。它唯一的非线性在于 $A(X)$ 里面"怎么分配权重"，没有能力对单个 token 的表示做非线性加工。

这件事有一个定量的结果：Dong, Cordonnier & Loukas (2021) 证明，**去掉残差和 MLP 的纯 attention 堆叠**，输出会随深度以双指数速度坍缩到秩 1，即所有 token 的表示趋于相同。残差和 FFN 正是抵抗这种坍缩的两个部件。
