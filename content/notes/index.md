Evergreen notes are the actual garden. Each one holds a single idea, titled as a
claim rather than a topic, and gets revised whenever I learn something that changes it.

The rules I try to follow:

1. **One idea per note.** If the title needs an "and", it's two notes.
2. **Title it as a claim.** "Spaced repetition beats rereading" is a note. "Memory" is a folder.
3. **Write for a stranger.** Including future me, who will not remember the context.
4. **Link generously.** A note with no links is a note that will never be found again.
5. **Revise in place.** Don't append a new note when the old one was wrong — fix the old one.

## Maturity

- 🌱 **Seedling** — a thought, possibly wrong, written down so it doesn't escape
- 🌿 **Budding** — has structure and some evidence, still moving
- 🌳 **Evergreen** — I'd defend this, and it changes slowly now

Every note declares its stage in frontmatter, so nothing here pretends to be more
settled than it is.
